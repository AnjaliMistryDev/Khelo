# 🎮 Khelo — Free Online Games

A kid-friendly web arcade with **145 free games** — no downloads, no sign-up. Works on any phone or computer.

🔗 **Play:** https://anjalimistrydev.github.io/Khelo/

## Features
- 145 games: Solitaire, Tetris, Sudoku, Wordle, Bubble Shooter, Battleship, Snake, 2048, Chess & more
- 🪙 Earn coins → buy 16 themes & 9 avatars
- 🏅 Badges, 📋 daily/weekly tasks, 🎡 spin wheel, 🔥 streaks
- 🇮🇳 English / ગુજરાતી / हिन्दी
- 💾 Progress saves in your browser, with backup & transfer

## Run locally
Keep `index.html` and `style.css` in one folder, open `index.html`. Done!

**Tech:** Pure HTML + CSS + JavaScript — no frameworks, no server.
